# Sistema de gestão — Bebop Som e Luz

Sistema de gestão da jornada do cliente para a Bebop Som e Luz, empresa
de locação de equipamentos de som e luz para eventos.

Cobre o caminho completo de um evento: orçamento para o cliente,
verificação de disponibilidade do material, contrato e checklist de
logística para a equipe de campo.

## Problema que resolve

Todo o controle de estoque e disponibilidade vive hoje na memória de
uma pessoa, que confere material presencialmente no galpão. O sistema
torna essa informação consultável em segundos e evita que o mesmo
equipamento seja comprometido em dois eventos na mesma data.

## Stack

Next.js (App Router) · SQLite via Prisma · Tailwind CSS · Vitest

Banco em arquivo local: roda sem depender de internet.

## Estado

Em desenvolvimento. Primeira entrega é um protótipo funcional com o
catálogo real da Bebop, para validação com o cliente.
